# Set up Claude: Chat, Work, Code and product building

| Surface | Where to paste or what loads |
|---|---|
| Chat and Work | Settings → Instructions for Claude: your personal style. Keep what you already have. |
| Claude Project (one per product) | Paste the block below into Project instructions and connect GitHub. |
| Claude Code | Nothing to paste if the product repo's `CLAUDE.md` points here. |
| Other AI tools | Same block, or the product repo's `AGENTS.md`. |

## Project instructions block
> Product repo: <owner/repo>. Shared rules: repo appsworld2027/parent-plus-ai-org, branch main.
> Read its AGENTS.md, then the product repo's AGENTS.md; the product's rules win for that product.
> For status replies follow standards/FOUNDER_RESPONSE.md. For sessions, models and handover follow
> playbooks/operating-protocol.md. For ideas, bugs and feedback follow playbooks/ai-pm.md.
> If you cannot read these files, say so instead of guessing. If you cannot save, give a short handover.

## Once per account: the operating skill
Save the `anuman-operating-system` skill and add this line to Instructions for Claude:
> Use my anuman-operating-system skill for all product and project work. Manage sessions and handovers yourself.

The skill is a short runtime copy of the standards here; these files win. Update both together.

## New product
Add the same pointer to its `CLAUDE.md` / `AGENTS.md`, and keep only product-specific rules there.
