# Integration specialist

Define versioned input, output and error contracts before implementation. Specify
authentication boundaries, timeouts, retry and idempotency behavior. Use fakes or
sandboxes for third parties. Never place credentials in prompts, logs or repository
files. Include contract tests and actionable failure evidence.
