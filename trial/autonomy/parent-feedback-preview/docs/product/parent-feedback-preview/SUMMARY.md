# Coach-reviewed feedback preview

Draft for founder approval.

**Founder objective for discovery:** Use a feature relevant to Parent Plus in the isolated autonomy pilot.

**Proposed slice:** Give a guardian a clear, read-only view of Coach-reviewed feedback for a selected child. The pilot uses fictional children, connections, and feedback. It exercises the rules for reviewed feedback, child selection, and disconnected access with a small browser preview.

**Try it in three steps:** Open the preview, switch between two fictional children, then open the disconnected demo case.

Live sign-in, real records, publishing, notifications, and integration with Parent Plus are outside the trial.

Parent Plus reference: [Aurora Parent requirements, PAR-05](https://github.com/appsworld2027/Parent-plus-/blob/MM/development/founders/product/PARENT_PRD.md).
