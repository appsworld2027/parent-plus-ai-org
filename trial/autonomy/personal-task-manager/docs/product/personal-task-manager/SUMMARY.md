# Personal Task Manager

Draft for founder approval.

**Founder objective used for discovery:** Personal Task Manager.

**Proposed audience and outcome:** One person can quickly capture a task, see what remains, and mark work complete. A simple daily list is the recommended first slice. Progress carries across reloads in the same browser. The isolated preview uses fictional tasks and stores entries in that browser.

**Try it in three steps:** Open the preview and add “Buy milk”. Mark it complete, then reopen it. Reload and confirm the saved status.

**Scope deferred:** Editing and deletion, due dates, reminders, accounts, sharing, and cross-device sync. No production deployment.
