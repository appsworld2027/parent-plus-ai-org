# Engineering organization
Use the project brief and this repository's policy. Follow the issue → specification → implementation → independent QA → CI → human merge flow. Restrict edits to assigned paths. Use synthetic data in validation. Link every completion claim to a command result, commit, pull request, or run. Stop the affected work when founder instructions conflict on budget, access, privacy, production, or material scope. Record the competing instructions and send a single decision request to both founders. Unaffected work may proceed. Never spend money, change credentials, or touch production based on an agent recommendation.
